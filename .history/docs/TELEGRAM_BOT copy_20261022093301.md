# Заявки на консультацию в Telegram

Сайт отправляет **все заявки** в Telegram. В сообщении: **страница**, **секция**, контакты, дата, статус и кнопки для двух менеджеров (хозяин + помощница).

---

## 1. Создать бота

1. [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Токен → `TELEGRAM_BOT_TOKEN`.

---

## 2. Куда слать заявки (рекомендуем группу на двоих)

**Лучший вариант для пары менеджеров** — общая группа:

1. Создайте группу, например «Rim Studio — заявки».
2. Добавьте **обоих** менеджеров и **бота**.
3. Напишите в группе любое сообщение.
4. Откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` и возьмите `chat.id` группы (часто отрицательный, `-100…`).
5. Поставьте в `TELEGRAM_CHAT_ID`.

Заявки приходят в группу — оба видят одно сообщение; кто нажал кнопку, то имя и попадает в статус.

### Личный чат с ботом

Можно и личку (как сейчас): `chat.id` положительный, только один человек видит чат.

### Ограничить, кто может жать кнопки

В группе посторонние теоретически тоже могут нажать кнопку. Чтобы только вы двое:

1. Узнайте свой Telegram user id ([@userinfobot](https://t.me/userinfobot)).
2. В `.env.local`:

```env
 TELEGRAM_ALLOWED_USER_IDS=111111111,22222222
```
