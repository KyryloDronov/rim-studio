# Данные для юридических страниц сайта

На сайте есть **Политика конфиденциальности** (`/legal/privacy`) и **Условия использования** (`/legal/terms`). Тексты заточены под студию шиномонтажа и покраски дисков в **Варшаве, Польша** (RODO / GDPR).

Часть реквизитов подставляется автоматически из одного файла — вам нужно заполнить их один раз.

---

## 1. Где править реквизиты на сайте

Файл: **`src/content/legal-entity.ts`**

| Поле | Что указать | Пример |
|------|-------------|--------|
| `companyName` | Полное юридическое название | `Rim Studio Sp. z o.o.` |
| `brandName` | Бренд на сайте | `Rim Studio` |
| `registeredAddress` | **Полный адрес седьбы** (улица, индекс, город) | `ul. Inwestycyjna 9, 05-800 Pruszków` |
| `nip` | NIP (10 цифр) | `1234567890` |
| `krs` | KRS | `0000123456` |
| `regon` | REGON | `123456789` |
| `email` | Контакт для клиентов и по данным | `hello@rim-studio.pl` из `studio-location.ts` |
| `phone` | Телефон студии | уже из `studio-location.ts` |
| `city` / `country` | Город и страна | `Pruszków`, `Polska` |

Сейчас в файле стоят **заглушки** (`0000000000`, «адрес до uzupełnienia») — замените на реальные данные до публикации.

После правки пересоберите/перезапустите сайт — плейсхолдеры `{{nip}}`, `{{companyName}}` и т.д. в текстах RU/PL обновятся сами.

## 2. Что желательно подготовить (вне кода)

Эти материалы не обязательно хранить в репозитории, но юрист/бухгалтер обычно их запрашивает:

1. **Выписка из KRS** или актуальные данные из rejestr.io — для проверки названия и адреса.
2. **NIP и REGON** — для счетов и политики.
3. **Кто отвечает за данные** — достаточно общего e-mail (`hello@rim-studio.pl`); отдельный IOD (инспектор по защите данных) для малого бизнеса часто не нужен, но можно назначить контактное лицо.
4. **Список подрядчиков**, которым уходят данные:
   - хостинг (Vercel / VPS — укажите в политике при необходимости);
   - **Telegram** (заявки с формы консультации) — см. [TELEGRAM_BOT.md](./TELEGRAM_BOT.md);
   - SMS-шлюз, если подключите рассылку;
   - бухгалтерия / CRM, если появятся.
5. **Cookies / аналитика** — если подключите Google Analytics, Matomo и т.п., нужно обновить раздел 8 в `ru.ts` / `pl.ts` (`pages.privacy.sections`) и, при необходимости, баннер согласия на cookies.
6. **Сроки хранения** — в политике указано ориентировочно (24 месяца для заявок). При другой практике поправьте тексты в словарях:
   - `src/i18n/dictionaries/ru.ts` → `pages.privacy`
   - `src/i18n/dictionaries/pl.ts` → `pages.privacy`

## 3. Где лежат тексты политики

| Язык | Файл |
|------|------|
| Русский | `src/i18n/dictionaries/ru.ts` → `pages.privacy`, `pages.terms` |
| Польский | `src/i18n/dictionaries/pl.ts` → `pages.privacy`, `pages.terms` |

Ссылки «политика конфиденциальности» в формах ведут на **`/legal/privacy`**, условия акции (когда включены) — на **`/legal/terms`**. В футере и в меню («Документы») — обе страницы.

---

## 4. Проверка после заполнения

1. Откройте `/legal/privacy` и `/pl/legal/privacy`.
2. Убедитесь, что адрес, NIP, KRS и название компании отображаются корректно.
3. Проверьте футер: «Политика конфиденциальности» → та же страница.
4. Отправьте тестовую заявку с баннера — в Telegram должно прийти сообщение (если настроен бот).

---

## 5. Важно

Тексты на сайте — **шаблон под типичную студию в Польше**, а не индивидуальная юридическая консультация. Перед официальной публикацией имеет смысл показать финальную версию политики польскому юристу (RODO + ustawa o świadczeniu usług drogą elektroniczną).

При смене формы собственности, адреса или новых услуг (обработка данных за пределами ЕЭЗ и т.д.) — обновите `legal-entity.ts` и соответствующие разделы в словарях.
