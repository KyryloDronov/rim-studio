# Заявки на консультацию в Telegram

Сайт отправляет **все заявки** в Telegram. В сообщении: **страница**, **секция**, контакты, дата, статус и кнопки для двух менеджеров (хозяин + помощница).

---

## 1. Создать бота

1. [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Токен → **`TELEGRAM_BOT_TOKEN`**.

---

## 2. Куда слать заявки (рекомендуем группу на двоих)

**Лучший вариант для пары менеджеров** — общая группа:

1. Создайте группу, например «Rim Studio — заявки».
2. Добавьте **обоих** менеджеров и **бота**.
3. Напишите в группе любое сообщение.
4. Откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` и возьмите **`chat.id`** группы (часто отрицательный, `-100…`).
5. Поставьте в **`TELEGRAM_CHAT_ID`**.

Заявки приходят в группу — оба видят одно сообщение; кто нажал кнопку, то имя и попадает в статус.

### Личный чат с ботом

Можно и личку (как сейчас): `chat.id` положительный, только один человек видит чат.

### Ограничить, кто может жать кнопки

В группе посторонние теоретически тоже могут нажать кнопку. Чтобы только вы двое:

1. Узнайте свой Telegram user id ([@userinfobot](https://t.me/userinfobot)).
2. В `.env.local`:
   ```env
   TELEGRAM_ALLOWED_USER_IDS=111111111,222222222
   ```

## 3. Переменные окружения

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
# TELEGRAM_ALLOWED_USER_IDS=  # опционально
# TELEGRAM_WEBHOOK_SECRET=     # только прод webhook
```

На проде те же переменные в Vercel / хостинге + redeploy.

## 4. Что умеет бот в чате

| Действие | Как |
|----------|-----|
| **Позвонить / WhatsApp** | Кнопки под заявкой (`tel:` / wa.me) |
| **✅ Принято** | Статус + имя из Telegram |
| **⏳ Перезвонить** | Нужен повторный звонок |
| **✔️ Закрыто** | Сделка завершена |
| **❌ Отказ** | Не актуально |
| **Заметка** | **Ответьте реплаем** на сообщение заявки — текст добавится в блок «Заметки» |
| **📅 Когда приедет** | После «Принято» / «Перезвон» — выбор времени визита (кнопки или своя дата) |
| **📞 Когда перезвонить** | То же для договорённости о звонке |
| **⏰ Напоминание** | За **15 минут** до визита и до перезвона — ответ на сообщение заявки в чате |

Время в заявке попадает в блок **«── План ──»** (🚗 визит / 📞 перезвон) с датой по Варшаве и именем, кто нажал.

**Своя дата:** бот откроет поле ввода внизу (ответ на его сообщение). Либо просто отправьте дату в чат — `15.10 14:30`. Чтобы бот увидел текст, локально должен работать `pnpm run telegram:poll` (или прод webhook).

После «Закрыто» / «Отказ» остаются только кнопки связи (позвонить / WhatsApp).

## 5. Локальная разработка — **без домена**

Telegram **не шлёт webhook на `localhost`**. Для тестов кнопок на своём компьютере:

**Терминал 1** — сайт:
```bash
npm run dev
```

**Терминал 2** — long polling (тот же код, что webhook на проде):
```bash
pnpm run telegram:poll
```

Если pnpm пишет `ERR_PNPM_IGNORED_BUILDS` (esbuild) — в проекте уже разрешены build-скрипты в `pnpm-workspace.yaml`; выполните `pnpm install` и снова `pnpm run telegram:poll`.

Скрипт сам снимает webhook (если был), слушает кнопки и реплаи, и **проверяет напоминания** (файл `data/telegram-reminders.json`). **Домен не нужен.**

Остановка: `Ctrl+C` в терминале с `telegram:poll`.

## 6. Продакшен — webhook

Когда сайт на HTTPS:

1. `TELEGRAM_WEBHOOK_SECRET` — случайная строка (`openssl rand -hex 16`).
2. Регистрация:
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://ВАШ_ДОМЕН/api/telegram/webhook&secret_token=<SECRET>
   ```
3. На проде **не** запускайте `npm run telegram:poll` — только webhook.
4. **Напоминания на проде:** cron раз в 1–5 минут на  
   `GET https://ВАШ_ДОМЕН/api/cron/telegram-reminders`  
   с заголовком `Authorization: Bearer <CRON_SECRET>` (задайте `CRON_SECRET` в env; без секрета маршрут открыт — лучше всегда задать).

Снять webhook (чтобы снова работал poll локально):
```
https://api.telegram.org/bot<TOKEN>/deleteWebhook
```

## 7. Проверка заявки с сайта

1. `npm run dev` + при тесте кнопок `npm run telegram:poll`.
2. Отправьте форму на сайте.
3. В Telegram — блоки «Источник» / «Контакт», кнопки статусов.

---

## 8. Безопасность

- Токен только в `.env.local` / env хостинга, не в git.
- Утёк токен → BotFather `/revoke`.
